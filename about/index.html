About  ·  The Pixel Story

About this project.

The Pixel Story is a learning site that teaches the evolution of AI — from the first perceptron in 1957 through transformers, large language models, and today's agentic systems — one chapter at a time, through a single recurring character, Pixel. Rather than defining terms up front, each chapter tells a small illustrated story first; the vocabulary only shows up afterward, once the idea has already landed.

The idea and the curriculum arc were inspired by a Yann LeCun interview transcript that traced AI's development as a sequence of concrete breakthroughs rather than an abstract timeline — the same shape this site borrows for Pixel's own growth, chapter by chapter, decade by decade.

It was built with Claude, an AI coding agent from Anthropic, working from a written design and content specification: plain HTML, CSS, and vanilla JavaScript, no framework and no build step, so that publishing a change is just a `git push` to GitHub Pages.

It's aimed at a curious reader roughly 8–14 years old, but written so an adult with no machine learning background can learn something real from it too — simplified in framing, never in accuracy.
