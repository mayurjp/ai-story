Now you know the grown-up words

Tap one to see what it means.
Convolution +
What happens in : instead of taking in the whole photo at once, Pixel slides a small window across it, checking one little patch at a time. That sliding, patch-by-patch checking process is called convolution.
Filter +
The one specific thing Pixel's small window is checking for inside each patch in — one window might look for edges, another for curves. Each of those specific pattern-checkers is called a filter.
Feature map +
After sliding the window over every patch in , Pixel has a mark for what it found in each spot — laid out in the same grid shape as the photo, in . That grid of results is called a feature map.
ConvNet +
The name for the whole machine built from stacking patch-scanning steps like on top of each other, so later scans combine what earlier ones already found. A network built this way is called a convolutional neural network, or ConvNet for short.
Computer vision +
The name for the whole field of getting machines to understand pictures the way Pixel just did in this story — turning patches of pixels into a recognized shape by . That field is called computer vision.
