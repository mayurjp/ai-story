Masking +
The torn-out word itself, sitting empty in the page from onward — a gap Pixel has to guess. Deliberately hiding a piece of something so a learner has to predict it is called masking.
Context +
Everything around the gap that Pixel actually reads to make its guess in — the words before and after the blank. The surrounding information a guess gets based on is called context.
Self-supervised learning +
The real trick in : nobody sits with Pixel and says "the answer is dog" the way they did back when Pixel was first learning shapes. The book already contains the answer — it was just torn out — so Pixel checks its own guess against the actual missing word, no separate teacher required. Learning this way, by testing yourself against material that already holds its own answers, is called self-supervised learning.
Pretraining +
Doing this same fill-in-the-blank guessing over and over, on thousands of pages, before Pixel is ever asked to do anything else — what's happened by . Building up a broad base of knowledge this way, before specializing in any one task, is called pretraining.
