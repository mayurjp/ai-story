The Closed-Book problem

Pixel's training finished last year. When asked: "What did the rover discover on Mars last Tuesday?", Pixel has no memory of last Tuesday. If it tries to guess from memory (closed-book), it will hallucinate!

Now you know the grown-up words

How enterprise search engines and smart assistants answer questions:

📚 RAG (Retrieval-Augmented Generation)

Fetching relevant private or fresh documents from a database and feeding them into the AI's prompt.

🌌 Vector Embedding

Converting sentences into mathematical coordinates where similar ideas land in the same neighborhood.

🗄️ Vector Database

A lightning-fast library designed to search millions of document coordinates in milliseconds.

📌 Citation / Grounding

Providing the exact webpage or document source link so users can verify the answer themselves.
