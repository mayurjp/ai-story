The Static Knowledge Problem

LLM weights are frozen upon training completion. Fine-tuning for every new internal PDF or yesterday's news is prohibitively expensive. RAG solves this by retrieving relevant context dynamically at query time.

Mathematical Architecture

Vector similarity search and context injection:

🌌 Vector Embedding Model

Maps text chunks into dense continuous space e ∈ R¹⁵³⁶ (e.g. OpenAI text-embedding-3).

📐 Cosine Similarity

sim(u, v) = (u · v) / (||u|| ||v||). Geometric angle similarity between query and document vectors.

⚡ HNSW Indexing

Hierarchical Navigable Small World graphs enable sub-millisecond approximate nearest neighbor (ANN) search over billions of vectors.

✂️ Chunking & Re-ranking

Splitting documents into 512-token chunks with 10% overlap, followed by a Cross-Encoder reranker for precision.

Python In-Memory Vector Search (Cosine Similarity) 

import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

# Simulated Document Corpus Embeddings (dim = 4)
corpus = {
    "doc_1": ("Q3 Revenue was $4.2B, up 15% YoY.", np.array([0.92, 0.12, 0.05, 0.31])),
    "doc_2": ("Our offices will be closed on Thanksgiving.", np.array([0.05, 0.88, 0.45, 0.10])),
    "doc_3": ("Server downtime maintenance on Sunday.", np.array([0.15, 0.20, 0.90, 0.12]))
}

# User Query: "What was our quarterly revenue?"
query_vec = np.array([0.95, 0.08, 0.02, 0.28])

# Top-1 Retrieval Search
best_doc, best_score = None, -1.0
for doc_id, (text, vec) in corpus.items():
    score = cosine_similarity(query_vec, vec)
    if score > best_score:
        best_score = score
        best_doc = (doc_id, text)

print(f"Retrieved: {best_doc[0]} (Similarity: {best_score:.3f})")
print(f"Content: '{best_doc[1]}'")
