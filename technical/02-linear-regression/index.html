Continuous numeric prediction and Ordinary Least Squares (OLS): Mean Squared Error (MSE) loss functions, gradient descent optimization, and server cluster cost estimation.

Predicting Continuous Quantities

Unlike classification (Yes/No), Regression predicts continuous real numbers (e.g. monthly AWS cloud server cost based on allocated CPU cores).

Mathematical Formulation

How linear models optimize slopes via loss gradients:

📐 Linear Hypothesis

ŷ = w · x + b. Predicts output ŷ as a linear function of input feature x.

📉 Mean Squared Error (MSE)

L = (1/N) · Σ (y_i - ŷ_i)². Squares residuals to heavily penalize large errors.

⚡ Gradient Descent

w ← w - η · (∂L/∂w). Takes steps proportional to the negative loss gradient to reach minimum error.

🎯 Closed-Form Solution (OLS)

w = (X^T · X)⁻¹ · X^T · y. Direct matrix inversion to compute exact optimal weights in one step.

From-Scratch Python / NumPy Implementation 

import numpy as np

# Training data: CPU cores (X) and monthly cost in $ (y)
X = np.array([2.0, 4.0, 6.0, 8.0])
y = np.array([50.0, 100.0, 150.0, 200.0])

w = 0.0
b = 0.0
lr = 0.01

# Gradient Descent Optimization Loop
for epoch in range(1000):
    y_pred = w * X + b
    error = y_pred - y
    
    # Partial derivatives
    dw = (2 / len(X)) * np.sum(error * X)
    db = (2 / len(X)) * np.sum(error)
    
    w -= lr * dw
    b -= lr * db

print(f"Optimal Weight (w): {w:.2f} ($/core)")
print(f"Optimal Bias (b): {b:.2f}")

# Predict 16 CPU cores server cost
print(f"16 Cores Cost: ${w * 16 + b:.2f}/mo")  # → $400.00/mo
