The Physics of Generative Diffusion

Unlike GANs that suffer from mode collapse, Denoising Diffusion Probabilistic Models (DDPM) treat generation as a thermodynamic inversion: systematically reversing the gradual addition of Gaussian noise.

Mathematical Architecture

DDPM (Ho et al., NeurIPS 2020) & Latent Diffusion (Stable Diffusion):

💨 Forward Process (q)

q(x_t | x_0) = N(x_t; √(ᾱ_t) x_0, (1 - ᾱ_t) I). Direct closed-form noise addition for any timestep t.

🧹 Reverse Denoising (p_θ)

A U-Net predicts the added noise ε_θ(x_t, t, c) conditioned on text embedding c.

🎛️ Classifier-Free Guidance (CFG)

ε̃_θ = ε_θ(x_t, ∅) + s · (ε_θ(x_t, c) - ε_θ(x_t, ∅)). Amplifies text prompt adherence using guidance scale s ≈ 7.5.

🌌 Latent Diffusion (SDXL)

Diffusing in a 8× compressed VAE latent space (64 × 64 × 4) for 50× faster sampling.

Python / PyTorch Reverse DDPM Denoising Step 

import torch

def ddpm_denoise_step(x_t, predicted_noise, alpha_t, alpha_bar_t, beta_t, t):
    """
    Computes single reverse diffusion step x_{t-1} from x_t
    """
    # 1. Compute predicted mean
    mean = (1 / (alpha_t ** 0.5)) * (
        x_t - (beta_t / ((1 - alpha_bar_t) ** 0.5)) * predicted_noise
    )
    
    # 2. Add stochastic noise if t > 0
    if t > 0:
        noise = torch.randn_like(x_t)
        sigma_t = beta_t ** 0.5
        x_prev = mean + sigma_t * noise
    else:
        x_prev = mean
        
    return x_prev
