Agentic AI, Tool Calling & Action Loops

Autonomous agent architecture: The ReAct (Reason + Act) design pattern, schema-validated JSON function calling, tool execution environments, and autonomous stopping conditions.

🤖
"ReAct Loop: Thought → Action(JSON) → Observation → Repeat"
Step 1 of 5

From Passive Chatbots to Autonomous Agents

Standard LLMs only generate text. Agentic Systems execute external tools (Python interpreters, bash terminals, SQL databases, REST APIs) in an iterative ReAct loop until a complex goal is accomplished.

Mathematical Architecture

The ReAct Framework (Yao et al., Princeton / Google 2022):

💭 Thought Step

The model reasons about current environmental state: Thought_t = LLM(Context_{t-1}).

🛠️ Tool Call (Structured JSON)

Emitting a schema-validated function payload: {"name": "query_sql", "args": {"limit": 5}}.

👁️ Observation Step

The external execution environment executes the tool and feeds stdout/results back as user prompt.

🛑 Stopping Condition

The agent detects goal completion and emits Final Answer, breaking the state machine loop.

Python Autonomous ReAct Agent Loop 

import json

# Simulated Environment Tools
TOOLS = {
    "run_sql": lambda q: "[{'error_count': 142, 'server': 'worker-04'}]",
    "restart_server": lambda s: f"Successfully restarted {s}. Status: Healthy."
}

def agent_react_loop(goal, max_steps=5):
    context = f"Goal: {goal}\n"
    
    for step in range(max_steps):
        # 1. LLM Generates Thought + Tool Action
        if step == 0:
            thought = "Inspect database for failing servers."
            action = {"tool": "run_sql", "arg": "SELECT server, count(*) FROM errors"}
        elif step == 1:
            thought = "worker-04 has 142 errors. Trigger server restart."
            action = {"tool": "restart_server", "arg": "worker-04"}
        else:
            thought = "Server is healthy. Goal accomplished."
            return f"FINAL ANSWER: Repaired worker-04. Goal complete."
            
        print(f"[{step+1}] THOUGHT: {thought}")
        print(f"[{step+1}] ACTION: Calling {action['tool']}({action['arg']})")
        
        # 2. Execute Tool & Observe Result
        tool_func = TOOLS[action['tool']]
        observation = tool_func(action['arg'])
        print(f"[{step+1}] OBSERVATION: {observation}\n")
        
        context += f"Thought: {thought}\nAction: {action}\nObservation: {observation}\n"

# Run Agent
agent_react_loop("Fix crashing worker nodes in production")
