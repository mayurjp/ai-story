Self-Supervised Masking & Pretraining

Unsupervised language representation learning: Masked Language Modeling (MLM / BERT), Vocabulary Softmax probability distributions, Cross-Entropy loss, and web-scale pretraining.

📖
"Predicting masked token from context: p('cat') = 84.5%"
Step 1 of 5

The Supervised Data Bottleneck

Hiring humans to label millions of images or text files is expensive and slow. Self-Supervised Learning creates infinite labels for free: take raw text, hide random words with [MASK], and train the model to guess the blanks!

Mathematical Architecture

How Masked Language Modeling learns syntax and semantics:

🎭 15% Random Masking

In BERT training, 15% of all tokens are selected: 80% replaced with [MASK], 10% random word, 10% unchanged.

📊 Softmax over Vocabulary

p(w | context) = exp(z_w) / Σ exp(z_v) across the full 30,000+ token vocabulary.

📉 Cross-Entropy Loss

L = -log(p(w_true | context)). Error forces the model to encode rich grammar and world knowledge.

🚀 Foundation Pretraining

Training on billions of unlabelled tokens builds a foundation model ready for fine-tuning on any downstream task.

PyTorch Masked Language Modeling Loss Example 

import torch
import torch.nn as nn
import torch.nn.functional as F

# Vocabulary: 0: [PAD], 1: [MASK], 2: The, 3: cat, 4: dog, 5: sat, 6: on, 7: mat
vocab_size = 8

# Ground truth token ID for "cat" is 3
target_token = torch.tensor([3])

# Model output logits for the [MASK] position (raw unnormalized scores)
mask_logits = torch.tensor([[ -2.1, -5.0, 0.5, 4.2, 2.1, -1.0, -2.5, 0.1 ]])

# 1. Compute Probabilities via Softmax
probs = F.softmax(mask_logits, dim=-1)
print(f"p('cat'): {probs[0, 3].item():.4f}")  # ~ 0.845 (84.5%)
print(f"p('dog'): {probs[0, 4].item():.4f}")  # ~ 0.112 (11.2%)

# 2. Compute Cross-Entropy Loss
loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(mask_logits, target_token)
print(f"Pretraining MLM Loss: {loss.item():.4f}")
