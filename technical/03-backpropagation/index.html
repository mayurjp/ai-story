Beyond Single Neurons: Multi-Layer MLPs

To solve non-linear problems (like robotic arm articulation or XOR logic), we stack neurons into hidden layers. But when the output misses the target, how do we adjust weights hidden deep inside?

Mathematical Architecture

The Calculus Chain Rule that powers all deep learning:

➡️ Forward Pass

a⁽¹⁾ = σ(W⁽¹⁾x + b⁽¹⁾) → ŷ = σ(W⁽²⁾a⁽¹⁾ + b⁽²⁾). Data flows forward layer-by-layer.

📉 Loss Function

L = ½(y - ŷ)². Quantifies the discrepancy between model prediction and ground truth.

🔗 Calculus Chain Rule

∂L/∂W⁽¹⁾ = (∂L/∂ŷ) · (∂ŷ/∂a⁽¹⁾) · (∂a⁽¹⁾/∂z⁽¹⁾) · (∂z⁽¹⁾/∂W⁽¹⁾).

⬅️ Backward Gradient Flow

Error gradients flow backward through matrix multiplications, updating every internal weight.

From-Scratch Python / NumPy Backpropagation 

import numpy as np

# Sigmoid and derivative
def sigmoid(z): return 1 / (1 + np.exp(-z))
def d_sigmoid(a): return a * (1 - a)

# XOR Dataset (Non-linearly separable)
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([[0], [1], [1], [0]])

# 2-Layer MLP Architecture (2 inputs -> 3 hidden -> 1 output)
np.random.seed(42)
W1 = np.random.randn(2, 3)
b1 = np.zeros((1, 3))
W2 = np.random.randn(3, 1)
b2 = np.zeros((1, 1))
lr = 0.5

# Training Loop
for epoch in range(10000):
    # 1. Forward Pass
    z1 = np.dot(X, W1) + b1
    a1 = sigmoid(z1)
    z2 = np.dot(a1, W2) + b2
    y_hat = sigmoid(z2)
    
    # 2. Backward Pass (Chain Rule Gradients)
    loss_grad = (y_hat - y)
    dz2 = loss_grad * d_sigmoid(y_hat)
    dW2 = np.dot(a1.T, dz2)
    db2 = np.sum(dz2, axis=0, keepdims=True)
    
    dz1 = np.dot(dz2, W2.T) * d_sigmoid(a1)
    dW1 = np.dot(X.T, dz1)
    db1 = np.sum(dz1, axis=0, keepdims=True)
    
    # 3. Weight Updates
    W2 -= lr * dW2; b2 -= lr * db2
    W1 -= lr * dW1; b1 -= lr * db1

print("XOR Predictions after Backpropagation:")
print(np.round(y_hat, 2))  # → [[0.], [1.], [1.], [0.]]
