The Curse of Image Dimensionality

Feeding a 1000×1000 pixel image directly into a standard dense network creates 3,000,000 weights per neuron! Convolutions solve this with Weight Sharing and local receptive fields.

Mathematical Architecture

How CNNs extract hierarchical features:

🎛️ Convolution Kernel (K)

A small learnable matrix (e.g. 3×3) that computes element-wise dot products across every local image patch.

🗺️ Feature Map

S(i, j) = (I * K)(i, j) = Σ Σ I(i-m, j-n) K(m, n). The resulting activated spatial representation.

📏 Stride & Padding

Stride: Step size of filter slide. Padding (Same): Zero-borders to maintain dimension.

📉 Max Pooling

Extracting the maximum activation in each 2×2 window to reduce resolution and achieve translation invariance.

From-Scratch 2D Matrix Convolution in Python / NumPy 

import numpy as np

def conv2d(image, kernel, stride=1):
    H, W = image.shape
    kH, kW = kernel.shape
    out_H = (H - kH) // stride + 1
    out_W = (W - kW) // stride + 1
    feature_map = np.zeros((out_H, out_W))

    for i in range(0, out_H):
        for j in range(0, out_W):
            patch = image[i*stride : i*stride + kH, j*stride : j*stride + kW]
            feature_map[i, j] = np.sum(patch * kernel)

    return feature_map

# 6x6 Synthetic Image (with a vertical bright edge)
img = np.array([
    [10, 10, 10, 0, 0, 0],
    [10, 10, 10, 0, 0, 0],
    [10, 10, 10, 0, 0, 0],
    [10, 10, 10, 0, 0, 0],
    [10, 10, 10, 0, 0, 0],
    [10, 10, 10, 0, 0, 0]
], dtype=float)

# Sobel Vertical Edge Detection Kernel
sobel_v = np.array([
    [ 1, 0, -1],
    [ 2, 0, -2],
    [ 1, 0, -1]
], dtype=float)

# Compute Convolution
edge_map = conv2d(img, sobel_v)
print("Detected Vertical Edge Feature Map:")
print(edge_map)
