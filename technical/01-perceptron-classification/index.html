The use case: filtering spam

Say you're building the simplest possible spam filter. Every incoming email gets reduced to a handful of numeric features — no NLP, no embeddings, just counts:

FeatureMeaning
x1Number of exclamation marks in the subject line
x2Contains the word "free" (1 or 0)
x3Ratio of capital letters in the subject (0–10 scale)
x4Number of links in the email body

Each email becomes a feature vector x = [x1, x2, x3, x4], and you want a function that maps that vector to a label: 1 for spam, 0 for not-spam. That mapping — a fixed set of input numbers to one of a small number of known output categories — is classification.

The model: one neuron

The smallest thing that can do this job is a single artificial neuron: it multiplies every input by its own tunable number (a weight), sums the results, and compares that sum against a cutoff (the threshold).

z = w₁x₁ + w₂x₂ + w₃x₃ + w₄x₄ + b
ŷ = 1 if z ≥ 0, else 0

Here b (the bias) is just the threshold folded into the same equation, moved to the other side — instead of asking "does the weighted sum cross this line," you ask "is the shifted sum ≥ 0." Same mechanism, one line of algebra apart. This exact architecture — weighted sum, threshold, one output — is the Perceptron, introduced by Frank Rosenblatt in 1957 (the same historical fact Chapter 1's story leans on).

Training: the perceptron learning rule

You don't hand-pick the weights. You show the model labeled examples — emails you already know are spam or not — and let it correct itself. This is supervised learning: every training example comes with the right answer attached.

After each prediction, the weights shift by how wrong the guess was:

error = y − ŷ
w ← w + η · error · x
b ← b + η · error

If the model guessed 0 on a true spam email, error = 1, and every weight nudges up in proportion to that feature's value — features that were "on" for this email get pushed to matter more next time. Guess right, error = 0, nothing moves. η (eta) is the learning rate, controlling how big each nudge is.

Code: training it from scratch

No frameworks needed — this is ~15 lines of NumPy:

import numpy as np

# feature vectors: [exclamations, has_free, caps_ratio, num_links]
X = np.array([
    [5, 1, 8, 3],   # spam
    [0, 0, 1, 0],   # not spam
    [3, 1, 6, 2],   # spam
    [1, 0, 2, 1],   # not spam
    [4, 1, 7, 4],   # spam
    [0, 0, 0, 0],   # not spam
])
y = np.array([1, 0, 1, 0, 1, 0])

w = np.zeros(X.shape[1])
b = 0.0
lr = 0.1

for epoch in range(20):
    for xi, yi in zip(X, y):
        z = np.dot(w, xi) + b
        y_hat = 1 if z >= 0 else 0
        error = yi - y_hat
        w += lr * error * xi
        b += lr * error

print("weights:", w)
print("bias:", b)

def predict(email_features):
    z = np.dot(w, email_features) + b
    return 1 if z >= 0 else 0

# a new email: lots of exclamation marks, says "free", high caps ratio
print(predict([6, 1, 9, 5]))  # → 1 (spam)
Where this breaks down. A single perceptron can only draw a straight-line (linear) decision boundary through feature space. If spam and not-spam aren't linearly separable — which real spam is not, once you use realistic features — no amount of training converges to a correct answer. That limitation is exactly what motivates stacking neurons into layers and training with backpropagation, covered in Chapter 3, "Pixel Takes a Shot."
