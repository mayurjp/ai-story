Binary Classification with a Single Neuron

Spam email classification using single artificial neurons: feature vector extraction, mathematical dot products, step activation functions, and the neuron learning update rule.

Step 1: Extracting the Feature Vector

An incoming spam email arrives: "Urgent: You won FREE prize money!!!". Standard ML converts raw text into numeric features: x = [4 exclamations, 1 free flag, 0.8 caps ratio, 3 links].

The Mathematical Foundations

How single artificial neurons calculate classifications in code:

🔢 Feature Vector (x)

A list of numeric measurements representing an object (e.g., word frequencies, caps ratios, counts).

⚖️ Weight Vector (w) & Bias (b)

The learnable parameters. The dot product w · x + b computes the pre-activation score z.

⚡ Step Activation (Heaviside)

The threshold function: if z ≥ 0 output 1 (Spam), otherwise output 0 (Legitimate Inbox).

🔄 Learning Rule

w_i ← w_i + η · (y - ŷ) · x_i. Weights shift whenever a training prediction is wrong.

From-Scratch Python / NumPy Implementation 

import numpy as np

# Training dataset: [exclamations, has_free, caps_ratio, num_links]
X = np.array([
    [4, 1, 0.8, 3],  # Spam (1)
    [0, 0, 0.1, 1],  # Inbox (0)
    [5, 1, 0.9, 4],  # Spam (1)
    [1, 0, 0.2, 0],  # Inbox (0)
])
y = np.array([1, 0, 1, 0])

# Initialize weights and bias to zero
w = np.zeros(X.shape[1])
b = 0.0
lr = 0.1  # learning rate (eta)

# Single Neuron Training Loop
for epoch in range(20):
    for xi, target in zip(X, y):
        z = np.dot(w, xi) + b
        y_hat = 1 if z >= 0 else 0
        error = target - y_hat
        w += lr * error * xi
        b += lr * error

print("Trained Weights (w):", w)
print("Trained Bias (b):", b)

def predict(email_features):
    z = np.dot(w, email_features) + b
    return "SPAM 🚨" if z >= 0 else "INBOX 📥"

# Test on a new email
print(predict([5, 1, 0.9, 4]))  # → SPAM 🚨
