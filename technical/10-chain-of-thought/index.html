Chain of Thought & System 2 Reasoning

Reasoning paradigms and test-time compute allocation: System 1 intuitive generation vs. System 2 deliberate search, Tree of Thoughts (ToT), Self-Consistency majority voting, and Process Reward Models (PRMs).

Why Direct Autocompletion Fails on Logic

LLMs have a constant number of layers per token. For complex logic, math, or coding, a single-pass autoregressive answer cannot allocate enough compute. Chain of Thought buys test-time compute by generating intermediate reasoning tokens.

Mathematical Architecture

Advanced reasoning paradigms in frontier AI:

🔗 Chain of Thought (Wei et al., 2022)

Prompting with "Let's think step by step" decomposes multi-step problems into solvable conditional sub-tokens.

🌲 Tree of Thoughts (ToT)

Exploring multiple reasoning branches with heuristic search (BFS/DFS) and backtracking when a dead end is detected.

🎲 Self-Consistency Sampling

Sampling k = 10 independent reasoning chains at Temperature T = 0.7 and taking the majority vote answer.

🏆 Process Reward Models (PRMs)

Scoring the mathematical validity of every intermediate reasoning step rather than only the final answer.

Python Self-Consistency Majority Voting Implementation 

from collections import Counter

def self_consistency_vote(reasoning_chains):
    """
    Extracts final answers from multiple CoT reasoning paths
    and returns the majority consensus answer.
    """
    answers = []
    for chain in reasoning_chains:
        # Extract numerical answer from the final line of reasoning
        final_line = chain.strip().split("\n")[-1]
        answers.append(final_line)
        
    counts = Counter(answers)
    majority_answer, votes = counts.most_common(1)[0]
    confidence = votes / len(reasoning_chains)
    
    return {
        "Consensus Answer": majority_answer,
        "Confidence": f"{confidence * 100:.1f}%",
        "Vote Breakdown": dict(counts)
    }

# 5 Independent sample paths
chains = [
    "Let ball = x. Bat = x + 1.00. 2x + 1.00 = 1.10 -> 2x = 0.10 -> x = $0.05\n0.05",
    "Ball is $0.05 and bat is $1.05. Total = $1.10.\n0.05",
    "Instant guess: 0.10",
    "1.10 - 1.00 = 0.10. Divide by 2 = 0.05\n0.05",
    "2x = 0.10 -> x = 0.05\n0.05",
]

result = self_consistency_vote(chains)
print(result)  # Consensus: 0.05 (80.0% Confidence)
